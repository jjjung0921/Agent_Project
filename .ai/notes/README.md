# Notes

임시 조사 메모를 두는 곳이다. Source of truth가 아니며, 다른 Agent가 반드시 읽어야 하는 정보는 여기에 두지 않는다.

- 용도: 조사 결과, 실험 로그, 디버깅 기록, 아직 결정되지 않은 아이디어
- 파일명: `YYYY-MM-DD-<topic>.md`
- 결론이 나면 적절한 곳(ADR, `ARCHITECTURE.md`, Phase PLAN, `HANDOFF.md`)으로 옮기고 메모는 삭제한다
- 다음 Agent가 읽어야 하는 메모는 `.ai/CURRENT.md`의 Relevant Documents에 명시한다
